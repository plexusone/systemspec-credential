# Release Notes v0.4.1

Released: 2026-11-25

## Fixed

- **Recording a deploy by pattern.** `record 'example-app/prod/*' deployed`
  recorded every credential the pattern matched, including planned ones
  not yet created, which then counted as deployed. A pattern's `deployed`
  or `verified` event now skips the credentials with no value: planned
  ones still to be created, and retired or revoked ones. It lists each it
  skipped, and fails when none of the matches has a value. Active
  credentials with nothing recorded keep the event, since their values
  exist. Other events, and a single ID, are recorded as before.

## Upgrading

No change is needed. A deploy script that records by pattern now leaves
planned credentials as to be created.
