# Release Notes v0.4.0

Released: 2026-11-22

## Highlights

A credential can say the exact form of its value, so a tool can make it
rather than a person reading `generation.spec`.

## Added

- **Value format.** `generation.format` is the value's exact form, while
  `spec` stays the description people read. `Formats` lists the formats
  and `Format.Random` tells random bytes from keys:
    - `hex32`: 32 random bytes, hex encoded.
    - `base64url32`: 32 random bytes, base64url without padding.
    - `p256-pem`, `ed25519-pem`, `rsa3072-pem`: a private key, PKCS #8,
      PEM.
- **Validation.** An unknown format is refused. A random-bytes format
  needs method `random`, and a key format needs method `keypair`. The
  registry schema lists the formats.

## Upgrading

The field is optional, so existing registries stay valid and the format
version is still 1. Add `format` to the credentials a tool should make,
such as with `credforge generate`.
