# Release Notes v0.2.0

Released: 2026-11-20

## Highlights

`handling` can now say an **AI agent**, acting for an operator, does a
stage. Each of `generate`, `distribute` and `rotate` is one of:

| Actor | Meaning |
|---|---|
| `human` | A person, by hand: a console, or a command they run |
| `agent` | An AI agent acting for an operator, such as a coding agent running a command; the operator approves what it cannot undo |
| `system` | A deterministic program, such as a deploy tool or a CI workflow |

## Added

- The `agent` actor, listed in the registry schema.
- `Handling.StagesBy(actor)` and `Handling.Agentic()` list the stages an
  actor does; `Handling.Responsible()` gives the most hands-on actor of
  the three stages: a person if one does any stage, else an agent, else a
  system.
- Every report counts the credentials an agent handles with no person
  involved, and each stage's agent count. The HTML report has a Handled
  column.

## Changed

- `Handling.Automatic()` is true only when a system does every stage. A
  credential an agent handles is no longer counted as automatic.

## Upgrading

Registries that use only `human` and `system` need no change.
