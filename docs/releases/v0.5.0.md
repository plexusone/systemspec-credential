# Release Notes v0.5.0

Released: 2026-11-28

## Added

- **Resend as a well-known issuer.** `IssuerResend` (`resend`) names
  Resend, which sends an application's email, beside `stripe` and
  `google-cloud`. `Issuers` lists it, and the registry schema gives it as
  an example of an issuer type.

## Upgrading

No change is needed. A registry that already wrote `"type": "resend"` is
unchanged: any lowercase slug was allowed before, and still is.
